Custom Block & Properties

Define hardness, blast resistance, sound types, map colors, and required mining tools for block instances.

02. ITEM PROPERTIES `Item.Properties` & `FoodProperties`

Custom Item & Food Properties

Define stack limits, rarity tiers, craft durability, and hunger/saturation restore values for custom food items. 

// Item & Food Properties Definition
public static final FoodProperties MAGIC_APPLE_FOOD = 
    new FoodProperties.Builder()
        .nutrition(8)
        .saturationMod(1.2f)
        .alwaysEat()
        .build();

public static final RegistryObject<Item> ENCHANTED_APPLE = 
    ITEMS.register("magic_apple", () -> new Item(

03. TILE ENTITIES `BlockEntity` & NBT Persistence

BlockEntity & Data Storage

Store persistent NBT state data (energy, inventory, processing timer) and execute server ticking logic. 

public class GrinderBlockEntity extends BlockEntity {
    private int progress = 0;

    @Override
    protected void saveAdditional(CompoundTag nbt) {
        nbt.putInt("GrindProgress", this.progress);
        super.saveAdditional(nbt);
    }
}

04. EVENT BUS `@SubscribeEvent` & Callbacks

Lifecycle & Event Handlers

Intercept gameplay events (entity damage, block placement, player login) and hook into initialization phases. 

@Mod.EventBusSubscriber(modid = "examplemod")
public class ModEvents {
    @SubscribeEvent
    public static void onPlayerJoin(PlayerEvent.PlayerLoggedInEvent event) {
        Player player = event.getEntity();
        player.sendSystemMessage(Component.literal("Welcome Modder!"));
    }
}

Workflow Overview

Your First Mod Developer Roadmap

A step-by-step workflow covering the full cycle from setup to compilation.

1

JDK 17 / 21 Setup & IDE Environment

Download Adoptium Temurin JDK 17 or JDK 21. Install IntelliJ IDEA Community Edition and configure the official Minecraft Development IntelliJ plugin for automatic template creation.

2

Clone Template & Run Gradle Source Generation

Download the official Forge MDK or Fabric Example Mod. Open your terminal in the project directory and execute:

./gradlew genSources (for Fabric/Forge sources decompilation)
3

Configure `mods.toml` or `fabric.mod.json`

Define metadata properties: `modId`, human-readable name, display version, license, author list, and dependency version constraints.

4

Register Game Elements & Write Code Logic

Attach custom blocks, items, block entities, and event listeners to your mod's event bus or Fabric entrypoint (`ModInitializer`).

5

Build Mod JAR Artifact

Execute Gradle build command to reobfuscate and compile your final distributable `.jar` artifact located in build/libs/.

./gradlew build
